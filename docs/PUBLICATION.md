# Publication Notes

This branch preserves the upstream ModemManager history and adds only the
MTK SoC plugin integration. Original ModemManager files keep their upstream
copyright and license notices.

Do not add:

- vendor Android `.so` files;
- modem firmware or boot images;
- NV/COW snapshots;
- SIM, IMEI, IMSI, ICCID, APN credentials or raw device logs;
- SSH credentials or private deployment paths.

Device protocol observations belong in redacted issue attachments or separate
local evidence, not in the source tree.
